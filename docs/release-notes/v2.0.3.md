# Vortex One v2.0.3

**In-place update over v2.0.2.** The host `applicationId` is unchanged, so this installs
straight over an existing Vortex One and keeps every cloned app, signed-in session,
firewall rule and Tor circuit. Verified on-device on an **Onn 4K Streaming Box (Android 14)**.

---

## 🐛 Guest-app fixes

- **Prime Video no longer crash-loops.** Its bundled Ignite/Megablast bootstrap
  (`assets/ignite-assets.tar`, gzip-compressed inside its own APK) never self-extracted
  inside the sandbox, so `files/lua/appBootstrap.js` was missing and the app died on every
  launch. It's now unpacked automatically on first run by a minimal built-in TAR reader.
- **YouTube TV works again.** A bundled Google client library swaps the process-wide
  default `SSLSocketFactory` for one that refuses to run without a validated Play Services
  install — throwing *"Attempted to use SSL unpatched"* for **any** TLS connection in that
  process, including our own DNS resolver. `CloudflareDnsResolver` now builds and warms its
  own isolated `SSLContext` early in the guest process lifecycle to win that race.

## 🔒 Network & privacy

- **Direct-IP DoH hardening.** `CloudflareDnsResolver` races `1.1.1.1` / `1.0.0.1` /
  `8.8.8.8` / `8.8.4.4` / `9.9.9.9` in parallel on port 443, retries a fully-failed
  resolution round instead of giving up on the first transient blip (Wi-Fi power-save,
  dropped handshake), and falls back only to the Google DoH JSON API — never to
  unencrypted UDP 53.
- **Host-process DNS contained** through the same DoH path.
- **`checkSignatures` interception hardened** so the faked Play Store `PackageInfo` is
  signed consistently and signature checks in guest apps pass.
- **Tor launch gating.** Tor-routed apps only start once a live circuit exists, and the
  Tor control port now requires cookie authentication.

## 🧩 Google Play Services

- **GMS is now self-healing and always installed.** `App.onCreate()` reinstalls it from
  the host on every launch regardless of what BlackBox's package registry claims — a stale
  "installed" flag with the files gone used to leave GMS-dependent apps broken
  indefinitely. There is no longer a Settings toggle to disable it.

## 🧹 Housekeeping

- **Removed a dormant footgun:** `ProxyVpnService` could capture all sandbox traffic into
  a TUN interface with no packet-forwarding loop behind it, silently killing network for
  the whole sandbox if ever enabled. It now refuses to start until real forwarding exists.
- **Removed dead code:** `FirewallBridge.kt` pointed at a non-existent Bcore package and
  had zero callers.
- **Release build:** R8 full-mode enabled; release APKs are named
  `VortexOne-v2.0.3-<abi>.apk` deterministically by Gradle.
- **Docs synced:** DEVELOPER.md / agents.md corrected to reflect DoH (not DoT), Tor
  SOCKS5 `9150`, and the frozen `applicationId`.
